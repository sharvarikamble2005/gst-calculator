**# GST Calculator – Python GUI Application**



**A simple desktop application built using Python and Tkinter to calculate GST and the final payable amount.**



**## Features**



**- Calculate GST based on the original amount and GST percentage.**

**- Display the final payable amount.**

**- Validate user input.**

**- Handle non-numeric input using try-except.**

**- Display error messages for invalid values.**

**- Simple graphical user interface.**



**## Technologies Used**



**- Python 3**

**- Tkinter**

**- Exception Handling**

**- Event-Driven Programming**



**## GST Calculation Formula**



**GST Amount = (Original Amount × GST Rate) / 100**



**Final Amount = Original Amount + GST Amount**



**### Example**



**| Description | Value |**

**|---|---:|**

**| Original Amount | ₹1,000.00 |**

**| GST Rate | 18% |**

**| GST Amount | ₹180.00 |**

**| Final Amount | ₹1,180.00 |**



**## Requirements**



**- Python 3.x**

**- Tkinter (usually included with Python)**



**## How to Run**



**1. Clone or download this repository.**

**2. Open a terminal in the project folder.**

**3. Run the application:**



**```bash**

**python gst\_calculator.py**

**```**



**Use `python3 gst\_calculator.py` if your system requires it.**



**## How to Use**



**1. Enter the original amount.**

**2. Enter the GST percentage.**

**3. Click the Calculate button.**

**4. View the calculated final amount.**
